# AP Exam Vocabulary Guide (応用情報技術者試験) 📚

**English Study Materials for Non-Native Japanese Speakers**

A comprehensive English study guide for the Japanese Applied Information Technology Engineer examination (応用情報技術者試験 - AP), designed specifically for non-native Japanese speakers working in Japan's IT industry.

## 🎯 About This Repository

The AP exam is entirely in Japanese and covers advanced IT topics with complex technical terminology. This repository provides:
- **Complete English explanations** of all exam topics
- **Japanese-English term mapping** for technical vocabulary
- **Practical examples** with bilingual annotations
- **Exam strategies** tailored for non-native speakers

**Focus**: Vocabulary, technical terms, and concept explanations to help understand exam questions and answers. We do NOT provide multiple choice questions - only the knowledge needed to comprehend them.

### For Complete Beginners
1. **Start with vocabulary** - Learn basic IT terms in Japanese
2. **Study one topic** at a time using the main guide
3. **Practice calculations** using provided formulas
4. **Focus on comprehension** rather than memorization

### For Advanced Learners
1. **Review weak areas** using the comprehensive guide
2. **Focus on calculation** problems and formulas
3. **Practice reading speed** with technical Japanese
4. **Memorize key terminology** for quick recognition

### Language Learning Tips

2. **Read questions aloud** to improve recognition
3. **Practice kanji writing** for better memorization
4. **Join study groups** with other non-native speakers

## 📅 AP Exam Information

### Exam Format
- **Duration**: 150 minutes (2.5 hours)
- **Questions**: 80 multiple choice questions
- **Language**: Japanese only
- **Passing Score**: 60% (48+ correct answers)
- **Format**: Paper-based examination

### Exam Schedule 2025
- **Spring Registration**: January 15 - February 28, 2025
- **Spring Exam Date**: April 20, 2025
- **Spring Results**: June 20, 2025
- **Fall Registration**: July 15 - August 31, 2025
